# Security

Report vulnerabilities through [GitHub's private form](https://github.com/byrnane/folden/security/advisories/new). Sign in when prompted. If the form is unavailable, keep sensitive details out of public issues.

Include the affected version, steps to reproduce with a small test example, and the possible impact. Leave out private documents, recovery or session files, credentials and personal paths. Response times and support are not guaranteed.

Fixes are considered only for the latest published beta. Reports can cover Markdown parsing, file access and saving, recovery, or the system webview.

## Безопасность

Сообщайте об уязвимостях через [приватную форму GitHub](https://github.com/byrnane/folden/security/advisories/new). При необходимости войдите в GitHub. Если форма недоступна, не публикуйте чувствительные подробности в Issues.

Укажите версию, шаги воспроизведения на небольшом тестовом примере и возможные последствия. Уберите личные документы, файлы восстановления и сессии, учётные данные и персональные пути. Срок ответа и поддержка не гарантируются.

Исправления рассматриваются только для последней опубликованной беты. Можно сообщать об ошибках разбора Markdown, доступа к файлам и сохранения, восстановления или системного webview.
