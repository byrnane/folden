# Security

**Private vulnerability reporting is enabled; the repository setting was verified on 2026-10-02.** Use [GitHub private vulnerability reporting](https://github.com/byrnane/folden/security/advisories/new) to send sensitive findings to the owner. Sign in to GitHub when prompted. If the form is unavailable, do not post sensitive details in public issues.

Describe the affected version, a minimal synthetic reproduction and the impact. Do not attach private documents, recovery/session files, credentials or personal paths. There is no promised response time or support contract.

Only the latest published beta is considered for fixes. Keep important document backups and update from the official release page. Local-first behavior does not put malformed Markdown, filesystem races or platform webviews outside the security scope.

Приватные сообщения об уязвимостях включены; настройка репозитория проверена 2026-10-02. Сообщайте об уязвимостях через private vulnerability reporting GitHub, используя искусственный пример; при необходимости войдите в GitHub. Если форма недоступна, не публикуйте чувствительные подробности в Issues. Срок ответа и договор поддержки не обещаются.
