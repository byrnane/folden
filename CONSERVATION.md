Репозиторий: [byrnane/folden](https://github.com/byrnane/folden). Основная ветка: `master`. Исходный коммит перед консервацией: `44616d912eae`.

## Назначение и состояние

Локальный Markdown- и текстовый редактор на Vue, TypeScript, Tauri и Rust. Активная разработка поставлена на паузу; репозиторий остается открытым для чтения и обратной связи. Публичная beta 0.12.0 и существующие скачивания сохраняются.

Реализованы визуальный и исходный режимы, вкладки и две панели, дерево папок, поиск, quick open, outline, шаблоны, autosave, восстановление, обработка внешних изменений, локальные изображения и печать/PDF. Интерфейс доступен на русском и английском.

Канонические данные — обычные пользовательские файлы. Профили, recovery, логи и резервные копии хранятся отдельно от документов. Консервация исходников не заменяет резервное копирование пользовательских документов.

## Релиз и ограничения

[Beta 0.12.0](https://github.com/byrnane/folden/releases/tag/v0.12.0) опубликована для Windows x64, macOS Apple Silicon и macOS Intel. Linux — самостоятельная сборка неизмененных исходников без официального пакета. Условия использования и ограничения беты остаются в README и [LICENSE.md](LICENSE.md).

Основная публичная ветка — master. Ветка `release/beta-0.12.0` сохранена для истории подготовки релиза. Номер версии и пакеты приложения в рамках консервации не меняются.

## Запуск и проверки

Точные требования, команды и платформенные ограничения описаны в [DEVELOPMENT.md](docs/DEVELOPMENT.md). После восстановления нужных Node.js и Rust toolchain:

```powershell
npm ci
npm run app:dev
```

Команды проверок и выпуска находятся в package.json, [RELEASE.md](docs/RELEASE.md) и существующих GitHub workflows. Для публикации документации консервации применяется обязательный ручной CI с четырьмя проверками, без изменения защиты master.

## Возвращение

Сначала прочитайте [состояние беты](docs/BETA-0.12.0.md), [архитектуру](docs/ARCHITECTURE.md) и [поведение продукта](docs/PRODUCT.md). Работайте с копиями важных документов. После очистки промежуточных артефактов первая нативная сборка займет больше времени; установленный редактор от папки исходников не зависит.
