# Dogfooding Folden

[English](DOGFOODING.md) | Русский

Используйте этот файл для записи реального ежедневного опыта перед следующим циклом разработки.

Автоматические и native-проверки беты 0.12 фиксируются отдельно: [BETA-0.12.0.ru.md](BETA-0.12.0.ru.md). Реальные ежедневные сессии этой беты пока не записаны. Добавляйте сюда фактические сессии; успешный тест с mock API или в браузере не является рабочей сессией.

## Сессии

Добавляйте одну запись для каждой реальной рабочей сессии:

```text
Дата:
Версия:
Окружение:
Проект/папка:
Продолжительность:
Использованные сценарии:
Заметки:
```

Обязательное покрытие:

- несколько полноценных рабочих сессий;
- реальный Markdown-проект;
- папка с большим количеством файлов;
- продолжительная сессия с несколькими вкладками;
- один документ, открытый в split view одновременно в Source- и Visual-режимах;
- переключение Visual/Source;
- autosave в реальной работе;
- recovery после принудительного закрытия приложения;
- внешнее изменение открытого файла;
- конфликт при одновременном редактировании;
- сценарии rename, create, delete и move в рабочем пространстве;
- большие Markdown-файлы;
- активный раздел оглавления, клавиатурную навигацию и click/drag карты документа в обоих режимах;
- скрытие файлов рабочего пространства через `.folden/workspace.json` с проверкой после перезапуска;
- локальные и удалённые изображения;
- сохранение layout и settings между запусками;
- несколько часов непрерывной работы;
- проверка потребления памяти и заметного замедления;
- быстрое открытие, поиск по проекту, поиск и замена в Source/Visual;
- шаблоны, относительные ссылки на документы и переходы назад/вперёд;
- импорт/вставка изображений и перенос файлов/папок с проверкой относительных путей;
- сохранение RU/EN и нативная печать/PDF длинного документа.

## Automated closeout 0.7

Release gate 0.7 покрыл регрессионный чек-лист редактора автоматическими E2E-тестами: переключение Visual/Source без dirty-state, мгновенную правку Visual перед Source, kitchen-sink save/reopen, сохранение raw HTML/frontmatter в Source, Source link/image dialogs, редактирование tables/task lists, сохранение scroll/selection и drag/drop payloads для вкладок, workspace-файлов и external paths.

Это не заменяет реальный dogfooding и smoke test установщика. Такие сессии фиксируются отдельно ниже.

## Automated closeout 0.8

Release gate 0.8 покрывает уникальные labels файлов, workspace-level ignores, muted folders, compact workspace actions, Outline, click/drag карты документа, сохранение её размеров и исключение plain text. В 0.8.2 добавлены активный пункт оглавления и клавиатурная навигация.

## Backlog проблем

Добавляйте только воспроизводимые ошибки или задачи с понятной пользовательской ценностью. Держите баги отдельно от идей будущих функций.
