# Как работает Folden

[English](PRODUCT.md) · Русский

Этот документ описывает поведение текущего приложения для разработчиков. Установка и возможности перечислены в [README](../README.ru.md), устройство кода — в [описании архитектуры](ARCHITECTURE.ru.md).

## Файлы и данные приложения

Сохранённые документы — обычные Markdown- или текстовые файлы, которые выбирает пользователь. Их содержимое, имена, папки и изображения принадлежат пользователю и остаются доступными за пределами Folden.

Приложение отдельно хранит настройки, недавние папки, раскладку панелей, копии для восстановления и диагностические журналы ограниченного размера. Сохранённый файл остаётся основной копией документа. Копии для восстановления хранят несохранённую работу, пока пользователь не восстановит или не отбросит её.

Folden сохраняет переводы строк и метку UTF-8 BOM. Он запоминает размер и время изменения файла, проверяет их перед записью и атомарно заменяет файл. Обнаруженное внешнее изменение вызывает конфликт, который разрешает пользователь. Отсутствие файла тоже отображается в интерфейсе.

## Режимы редактирования и панели

Markdown по умолчанию открывается в визуальном режиме; этот выбор можно изменить в настройках. Визуальный редактор работает с блоками: абзацами, заголовками, списками, таблицами и кодом. Режим исходного текста даёт доступ к самому Markdown. Обычные текстовые файлы открываются в режиме исходного текста и сохраняют свой формат.

Открытие документа и переключение режимов сохраняют его Markdown. Правки в визуальном редакторе затрагивают изменённые блоки; исходный текст остальных блоков сохраняется. HTML, HTML-комментарии, метаданные в начале файла (frontmatter), сноски, определения ссылок и пользовательские директивы остаются редактируемыми блоками исходного текста. В таких же блоках сохраняются изображения, смешанные с текстом, которые не помещаются в блочную схему визуального редактора.

У документа одно содержимое и общая история отмены и повтора для обоих режимов и панелей. Каждая панель хранит свой режим, выделение и положение прокрутки. Вкладки можно менять местами и переносить между двумя панелями. Приложение запоминает раскладку вкладок, активные документы, режимы и соотношение ширины панелей.

## Сохранение, закрытие и восстановление

Автосохранение по умолчанию включено для файлов, которые уже находятся на диске. В настройках задаются задержка, сохранение при потере фокуса окна и при смене документа. Если пользователь раньше отключил автосохранение, его выбор сохраняется. Новый черновик нужно впервые сохранить вручную, выбрав путь.

Приложение отслеживает несохранённые изменения. При закрытии документа или окна с такими изменениями оно предлагает сохранить их, отбросить или отменить закрытие. Сохранение копии записывает отдельный файл. Внешние изменения можно сравнить и разрешить перед записью.

Восстановление сохраняет все активные документы с несохранёнными изменениями: новые черновики и правки уже сохранённых файлов. После неожиданного завершения работы пользователь может восстановить или отбросить эти копии. Отложенные копии восстановления ограничиваются отдельно от активных документов после удаления дубликатов.

## Папки проекта, поиск и ссылки

Дерево папок загружает каталоги по мере их открытия. Игнорируемые имена задаются в настройках приложения. Пути, скрытые в конкретном проекте, хранятся в `.folden/workspace.json`; папка `.folden` скрыта в дереве. Удаление файлов выполняется через системную корзину.

Поиск по проекту читает поддерживаемые текстовые файлы UTF-8 и учитывает игнорируемые имена и скрытые пути. Поиск можно отменить; приложение сообщает о неполных результатах и пропущенных файлах. Символические ссылки не обходятся. Ограничения поиска:

| Ограничение               | Значение |
| ------------------------- | -------- |
| Размер проверяемого файла | 2 МиБ    |
| Совпадения                | 5000     |
| Элементы дерева           | 100000   |
| Уровни вложенности        | 32       |

Относительные Markdown-ссылки открывают документы внутри выбранного проекта; доступна история переходов назад и вперёд. Импорт локальных изображений и вставка из буфера обмена записывают изображения рядом с сохранённым документом в папку `<stem>.assets`.

При переносе `.md` или `.markdown` вместе с файлом переносится соседняя папка `<stem>.assets`, если она есть. Уже существующая папка ресурсов в месте назначения блокирует перенос. Содержимое документа и остальные пути к изображениям или ссылкам остаются прежними; после переноса относительные ссылки нужно проверить.

## Печать и доступ к сети

Для печати создаётся отдельный неизменяемый снимок текущего документа со светлым оформлением страницы. Неподдерживаемый Markdown выводится блоками исходного текста, недоступные изображения — заглушками. Разбивка на страницы, выбор принтера, место сохранения PDF, поля и завершение печати зависят от системного диалога и веб-компонента. Закрытие диалога само по себе не подтверждает успешную печать или экспорт.

Редактирование работает без учётной записи и подключения к интернету. В Folden нет телеметрии и облачной синхронизации. Сетевые изображения в визуальном режиме загружаются с разрешения для документа. Ссылки помощи открывают GitHub в браузере. Журналы остаются локальными, экспорт диагностики запускается отдельной командой.
