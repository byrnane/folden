# Folden 0.12.0 beta

A local-first Markdown workspace with Source and Visual editing, recovery, project search, local images, templates and printing. This public beta brings original branding, RU/EN documentation, clear terms and official packages for Windows and macOS. Linux is available only as a private self-build of the unmodified source.

**Beta software: bugs, crashes, and data loss may occur.** Folden is provided **“AS IS”, without warranties** under [LICENSE.md](https://github.com/byrnane/folden/blob/v0.12.0/LICENSE.md#warranty-and-liability). Keep independent backups of important documents.

## What's new

- Platform-aware paths and native file operations across the supported desktop targets.
- macOS Command shortcuts and native printing.
- About dialog with version, license, third-party notices and project links.
- Windows x64 NSIS, macOS Intel and Apple Silicon DMG.
- Locked Node/Rust versions, native CI, artifact privacy/architecture checks and SHA-256 checksums.

## Downloads and trust

[Download beta 0.12.0](https://github.com/byrnane/folden/releases/tag/v0.12.0). Choose the package for your system and compare its SHA-256 with SHA256SUMS.txt. The release also contains LICENSE.md and THIRD_PARTY_NOTICES.md. Windows requires WebView2 and macOS requires 14 or newer. Linux has [private self-build instructions](https://github.com/byrnane/folden/blob/v0.12.0/docs/DEVELOPMENT.md#linux-self-build), without an official package or native acceptance in this beta.

Windows binaries are unsigned. macOS binaries use an ad-hoc signature and are not notarized. Operating systems may show a first-launch warning. All three packages passed CI and payload verification. See [the verification record](https://github.com/byrnane/folden/blob/master/docs/BETA-0.12.0.md) for native coverage and remaining limitations.

Official binaries may be used free of charge for personal and commercial work. Author source is provided for inspection with a limited private Linux self-build permission under LICENSE.md. User documents remain yours; third-party components retain their own terms.
