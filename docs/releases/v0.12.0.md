# Folden 0.12.0 beta

A local-first Markdown workspace with Source and Visual editing, recovery, project search, local images, templates and printing. This beta prepares Folden for public use with original branding, RU/EN documentation, clear terms and packages for Windows, Linux and macOS.

## What's new

- Platform-aware paths and native file operations across the supported desktop targets.
- macOS Command shortcuts and native printing.
- About dialog with version, license, third-party notices and project links.
- Windows x64 NSIS, Linux x64 AppImage/deb, macOS Intel and Apple Silicon DMG.
- Locked Node/Rust versions, native CI, artifact privacy/architecture checks and SHA-256 checksums.

## Downloads and trust

Choose the package for your system and compare its SHA-256 with SHA256SUMS.txt. The release also contains LICENSE.md and THIRD_PARTY_NOTICES.md. Windows requires WebView2, Linux targets the Ubuntu 22.04/WebKitGTK 4.1 baseline, and macOS requires 14 or newer.

Windows binaries are unsigned. macOS binaries use an ad-hoc signature and are not notarized. Operating systems may show a first-launch warning. Native platform acceptance and AppImage component attribution must be recorded before publishing this draft; see [the acceptance record](../BETA-0.12.0.md).

Official binaries may be used free of charge for personal and commercial work. Author source is provided for inspection only under LICENSE.md. User documents remain yours; third-party components retain their own terms.
