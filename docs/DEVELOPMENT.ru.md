# Разработка

[English](DEVELOPMENT.md) · [Архитектура](ARCHITECTURE.ru.md) · [Релиз](RELEASE.ru.md)

Руководство описывает разработку владельцем проекта и разрешённую самостоятельную сборку на Linux. Права на использование исходников и распространение сборок указаны в [лицензии](../LICENSE.md).

## Подготовка

Установите **Node 24.16.0** и **Rust 1.96.0** — версии из `.nvmrc` и `rust-toolchain.toml`. Выполните [требования Tauri](https://v2.tauri.app/start/prerequisites/) для своей ОС: C++ Build Tools и WebView2 на Windows, Xcode Command Line Tools на macOS, WebKitGTK 4.1 и библиотеки разработки на Linux.

Из корня репозитория:

```text
npm ci
npm run app:dev
```

Приложение для разработки использует идентификатор `com.folden.editor.dev` и отдельные настройки, сессии и данные восстановления. `npm run app:run` запускает последнюю локальную сборку для выпуска с профилем `com.folden.editor`. Перед заменой установленного приложения или очисткой профиля получите разрешение владельца и проверьте резервную копию.

## Самостоятельная сборка на Linux

Лицензия разрешает локально собрать неизменённые исходники для собственной личной или коммерческой работы. Изменение и распространение запрещены. Полные условия приведены в [LICENSE.md](../LICENSE.md).

Используйте закреплённые версии Node и Rust, установите [зависимости Tauri для Linux](https://v2.tauri.app/start/prerequisites/#linux). База сборки — Ubuntu 22.04 с WebKitGTK 4.1. Из корня репозитория:

```text
npm ci
npm run app:build
npm run licenses:check
npm run app:run
```

Команды создают локальный исполняемый файл без установщика. Сохраняйте сгенерированные уведомления о сторонних компонентах и соблюдайте их лицензии. Официальные пакеты беты доступны для Windows и macOS. Для Linux в этой бете нет официального пакета и записи о проверках на реальной ОС.

## Проверки владельца проекта

| Команда                    | Назначение                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| `npm run vue:dev`          | Интерфейс в браузере; доступ к файлам и системным диалогам требует настольного приложения    |
| `npm run vue:build`        | Проверка типов и сборка интерфейса                                                           |
| `npm run app:dev`          | Настольное приложение для разработки                                                         |
| `npm run app:build`        | Локальный исполняемый файл без установщика                                                   |
| `npm run app:run`          | Последняя локальная сборка для выпуска                                                       |
| `npm run quality`          | Версии, форматирование, типы, неиспользуемый код, циклы зависимостей, lint и модульные тесты |
| `npm run test:coverage`    | Модульные тесты с проверкой порогов покрытия                                                 |
| `npm run test:e2e`         | Тесты в Chromium; эталонные скриншоты записаны на Windows                                    |
| `npm run test:performance` | Отдельные проверки производительности интерфейса, браузера и нативного кода                  |
| `npm run test:release`     | Проверки скриптов выпуска                                                                    |
| `npm run privacy:check`    | Личные данные в отслеживаемых и неигнорируемых исходных файлах                               |
| `npm run licenses:check`   | Соответствие уведомлений закреплённым зависимостям                                           |

Перед первым запуском E2E установите браузер командой `npx playwright install chromium`. Проверки Rust запускаются из `src-tauri`:

```text
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

CI проверяет Rust на Windows x64 и обеих архитектурах macOS. Браузерные тесты запускаются на Windows. Проверки установленного настольного приложения записывайте отдельно; см. [статус проверок беты](BETA-0.12.0.ru.md).

## Результаты сборки и лицензии

Интерфейс собирается в `dist/`. Cargo использует `build/desktop/`, инкрементальная компиляция отключена. Сборки с явной целевой платформой записываются в `build/desktop/<target>/release/`. Проверка пакетов готовит файлы в `build/release/<target>/`. Для старого состояния репозитория задавайте отдельный каталог Cargo, чтобы его файлы не смешивались с текущими пакетами.

Vite создаёт `THIRD_PARTY_NOTICES.md` при разработке и сборке интерфейса. Файл и загруженные тексты лицензий игнорируются Git; официальные пакеты содержат полные уведомления. Генератор читает закреплённые графы зависимостей npm и Cargo для Windows, Linux и macOS. Он загружает недостающие исходники Cargo и проверяет закреплённые тексты лицензий по SHA-256. Первый запуск требует сети, следующие используют проверенные файлы из `.cache/`.

После изменения зависимостей:

```text
npm ci
npm run licenses:generate
npm run licenses:check
```

Перед сборкой пакетов проверьте уведомления, версии компонентов и ссылки на исходники. [Подготовка релиза](RELEASE.ru.md) описывает проверки пакетов и обязательные архивы исходников сторонних компонентов.

Храните личные документы, диагностику, кеши и локальные настройки `.codex` вне коммитов. Проверки приватности показывают имена файлов и причины, скрывая найденные значения. Искусственные пути разрешайте только точными записями тестовых примеров; остальные тесты должны проходить проверку.

## Работа над редактором

Код исходного и визуального редакторов загружается по требованию. Предупреждение Vite о размере этих частей ожидаемо. Сохраняйте неизменённый Markdown, неподдерживаемый синтаксис, форматы файлов, локализацию и содержимое пользовательских документов. [Архитектура](ARCHITECTURE.ru.md) описывает владельцев состояния, сохранение и восстановление. Реальные рабочие сессии записывайте в [журнал использования](DOGFOODING.ru.md).
