# Folden 0.12.0 beta

[English](BETA-0.12.0.md) · [Релиз](https://github.com/byrnane/folden/releases/tag/v0.12.0)

Folden — локальный Markdown-редактор с режимами Source и Visual, проектами, восстановлением, поиском, изображениями, шаблонами и печатью. Бета добавляет оформление публичного релиза и совместимую обработку путей для Windows, Linux и macOS.

## Изменения

- Документация RU/EN, собственный фирменный стиль и раздел «О приложении» с версией, условиями использования, лицензиями компонентов и ссылками проекта.
- Платформенные операции с файлами, совместимое чтение старых путей, безопасные сохранение и перенос без перезаписи назначения.
- Горячие клавиши с Command и системная печать для macOS.
- Windows x64 NSIS, Linux x64 AppImage/deb, macOS Intel/Apple Silicon DMG; зафиксированные версии инструментов и проверки содержимого готовых пакетов.
- Условия ознакомления с исходниками и бесплатного использования приложения, лицензии сторонних компонентов, проверки приватности и создание черновика релиза через CI.

Эти результаты относятся к локальному рабочему дереву. Официальные пакеты нужно собрать через CI из одного согласованного commit и проверить на реальных ОС до публикации. Во время локальных проверок установленное приложение и профиль пользователя не заменялись.

Windows-пакеты не подписаны, macOS использует ad-hoc подпись без нотариального заверения Apple. Минимальная macOS — 14+, базовая Linux-система — Ubuntu 22.04/WebKitGTK 4.1, Windows требует WebView2. Перед установкой проверьте источник и SHA256SUMS.txt.

Visual редактирует распространённый Markdown, оставляя неподдерживаемые конструкции как source-блоки. Перемещение переносит соседнюю assets-папку, но не переписывает все относительные ссылки. Печать зависит от webview и принтера; закрытие диалога не подтверждает успешный экспорт. Храните резервные копии важных документов.
