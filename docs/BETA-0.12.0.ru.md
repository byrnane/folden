Бета 0.12.0 опубликована 2026-10-03. Здесь записаны проверки пакетов Windows x64 и macOS Intel/Apple Silicon. Возможности и установка описаны в [README](../README.ru.md), изменения — в [примечаниях к выпуску](releases/v0.12.0.md).

## Проверки на реальных системах

Автор сообщил об успешных проверках Windows и macOS 2026-10-03. Модели компьютеров, версии ОС и отдельные результаты для обоих типов процессоров Mac в записи отсутствуют.

Отдельно нужно записать результаты следующих проверок:

- Установка Windows с UAC в Program Files и обновление старой установки в нестандартной папке.
- Буфер обмена ОС, диалоги печати и PDF, печать на физическом принтере.
- Несколько рабочих сессий по [проверке повседневной работы](DOGFOODING.ru.md).

У этой беты нет официального Linux-пакета и записанных проверок на реальной Linux-системе. Доступна [инструкция самостоятельной сборки](DEVELOPMENT.ru.md#самостоятельная-сборка-на-linux).

## Ограничения

Браузерные тесты используют имитацию системного API. Диалоги ОС, установщик и печать требуют проверки на реальных системах. Записанные ручные результаты относятся к компьютерам автора; остальные конфигурации Windows 10/11 и macOS 14+ пока не проверены.

В бете возможны ошибки, сбои и потеря данных. Храните отдельные резервные копии важных документов. Подробнее — в [условиях использования](../LICENSE.md#warranty-and-liability).

Сборка описана в [руководстве по выпуску](RELEASE.ru.md), редактирование, перенос файлов и печать — в [описании поведения приложения](PRODUCT.ru.md).
