# Folden 0.12.0 beta

[English](BETA-0.12.0.md) · [Релиз](https://github.com/byrnane/folden/releases/tag/v0.12.0)

Folden — локальный Markdown-редактор с режимами Source и Visual, проектами, восстановлением, поиском, изображениями, шаблонами и печатью. Публичная бета добавляет собственное оформление и совместимую обработку путей для Windows, Linux и macOS.

**Это бета: возможны ошибки, сбои и потеря данных.** Folden предоставляется **«как есть» (AS IS), без гарантий** по [LICENSE.md](../LICENSE.md#warranty-and-liability). Храните независимые резервные копии важных документов.

## Изменения

- Документация RU/EN, собственный фирменный стиль и раздел «О приложении» с версией, условиями использования, лицензиями компонентов и ссылками проекта.
- Платформенные операции с файлами, совместимое чтение старых путей, безопасные сохранение и перенос без перезаписи назначения.
- Горячие клавиши с Command и системная печать для macOS.
- Официальные Windows x64 NSIS и macOS Intel/Apple Silicon DMG; зафиксированные версии инструментов и проверки содержимого готовых пакетов. Для Linux доступна только приватная самостоятельная сборка неизменённых исходников.
- Условия ознакомления с исходниками и бесплатного использования приложения, лицензии сторонних компонентов, проверки приватности и создание черновика релиза через CI.

В выпуск входят проверенные файлы этого CI run без пересборки. Ручная приёмка ограничена общим сообщением владельца о Windows/macOS; она не подтверждает полную матрицу Windows 10/11 и устройств с macOS 14+.

Windows-пакеты не подписаны, macOS использует ad-hoc подпись без нотариального заверения Apple. Минимальная macOS — 14+, Windows требует WebView2. Перед установкой проверьте источник и SHA256SUMS.txt. Для Linux есть [инструкция приватной самостоятельной сборки](DEVELOPMENT.ru.md#самостоятельная-сборка-на-linux), официального пакета беты нет.

Visual редактирует распространённый Markdown, оставляя неподдерживаемые конструкции как source-блоки. Перемещение переносит соседнюю assets-папку, но не переписывает все относительные ссылки. Печать зависит от webview и принтера; закрытие диалога не подтверждает успешный экспорт. Храните резервные копии важных документов.

Официальные бинарники бесплатны для личной и коммерческой работы. Авторские исходники доступны для ознакомления с ограниченным разрешением на приватную Linux-сборку; изменение и распространение ограничены [LICENSE.md](../LICENSE.md). Права пользователя на его документы и лицензии сторонних компонентов регулируются отдельно.
