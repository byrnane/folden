# История изменений

## 0.12.0 - 2026-10-02

- Добавлены собственное оформление, документация на русском и английском и окно «О программе» с версией, лицензией и ссылками.
- Работа с путями и файлами адаптирована для Windows, Linux и macOS; сохранено чтение прежних путей.
- Добавлены сочетания клавиш с Command и системная печать на macOS.
- Подготовлены установщик NSIS для Windows и DMG для macOS Intel и Apple Silicon. Сохранены прежние издатель и идентификатор Windows-приложения. Для Linux предусмотрена самостоятельная сборка для собственного использования.
- Закреплены версии Node и Rust. CI проверяет три официальные платформы, финальные пакеты и контрольные суммы SHA-256.
- Добавлены условия бесплатного использования официального приложения, ознакомления с исходным кодом и личной Linux-сборки. В пакеты включены сведения о сторонних лицензиях; добавлена проверка на приватные данные.
- Добавлен ручной запуск workflow для создания черновика предварительного релиза.

## 0.11.0 - 2026-09-30

- Добавлены быстрое открытие документов, поиск по проекту и поиск с заменой в открытом документе.
- Добавлены шаблоны заметок, игровых дизайн-документов и видеосценариев, переходы по ссылкам на документы и история навигации.
- Добавлены импорт локальных изображений, вставка из буфера обмена и перенос файлов между папками проекта.
- Добавлены печать и сохранение в PDF через системный диалог.
- Интерфейс полностью переведён на русский и английский. Выбор языка сохраняется; при первом запуске используется системный язык.
- Исправлены повторное сохранение после ошибки, отмена «Сохранить как», одновременная перезагрузка с диска и редактирование, а также восстановление более 64 активных черновиков. Автосохранение включено по умолчанию.
- Исправлены сохранение исходного Markdown при изменении списков и таблиц, копирование блоков и безопасная замена файлов в Windows.
- Исправлены пути и разрешения загрузки изображений после изменений в визуальном режиме, а также разделители Markdown-блоков. Изображения внутри текста сохраняются как блоки исходного кода.
- Добавлены ручная CI-сборка Windows-беты с установщиком и контрольными суммами и тесты новых сценариев.
- Добавлен установщик на русском и английском: системная установка по умолчанию, сохранение прежнего пути. Для разработки выделен отдельный профиль.

- Визуальный режим и исходник используют общую историю правок и синхронизируют позицию через привязки к содержимому. Полные копии документа для истории больше не создаются.
