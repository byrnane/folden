# Changelog

## 0.2.0 - 2026-06-28

### Добавлено

* Добавлен визуальный Markdown-редактор на Tiptap 3.
* Добавлен source-режим на CodeMirror для Markdown и обычных текстовых файлов.
* Добавлено открытие workspace-папки и дерево файлов.
* Добавлены создание, переименование и перемещение файлов и папок в корзину.
* Добавлены вкладки для нескольких открытых файлов.
* Добавлен split-view на две редакторские панели.
* Добавлена базовая панель форматирования Markdown.
* Обновлён тёмный интерфейс с сайдбаром, вкладками и центрированным текстовым полотном.

### Ограничения

* Нет autosave и восстановления после сбоя.
* Нет произвольной сетки split-панелей и drag-and-drop вкладок.
* Нет таблиц, task lists, custom blocks, slash commands и backlinks.
* Удаление идёт через системную корзину.

## 0.1.0 - 2026-06-24

### Добавлено

* Создан первый Tauri 2 + Vue 3 + TypeScript + Vite каркас приложения.
* Подключён CodeMirror 6 как source-редактор.
* Добавлено создание нового документа.
* Добавлено открытие текстовых файлов через нативный диалог.
* Добавлено сохранение текущего файла через нативный диалог.
* Добавлен dirty state для несохранённых изменений.
* Добавлено отображение имени и пути текущего файла.
* Добавлена минимальная тёмная тема.
* Добавлены базовые документы по MVP, настройке окружения и выбору редакторного движка.

### Исправлено

* Добавлен npm-wrapper для Tauri, чтобы команда находила Cargo в стандартном Rustup-пути.
* Исключён `src-tauri/target` из Vite watcher, чтобы dev-режим не падал на locked `.exe` файлах Windows.
* Tauri identifier изменён на `com.folden.editor`.
* Упорядочены npm-скрипты для frontend и desktop режимов.
* Desktop build перенесён в `build/desktop`.

### Ограничения

* Нет вкладок.
* Нет workspace и дерева файлов.
* Нет автосохранения и восстановления после сбоя.
* Нет визуального блочного редактора.
* Нет переключателя темы.
