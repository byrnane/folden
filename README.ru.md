Folden — настольный редактор Markdown и обычного текста для заметок, статей, сценариев, документации и игровых дизайн-документов. Откройте файл или папку проекта, работайте в визуальном режиме или с исходным текстом. Документы хранятся на вашем компьютере.

В выпуск входят три установочных пакета, `SHA256SUMS.txt`, тексты лицензий и архив исходников NSIS, который требуется лицензией установщика.

| Система             | Пакет             | Требования        |
| ------------------- | ----------------- | ----------------- |

| macOS Apple Silicon | ARM64 `.dmg`      | macOS 14 и новее  |

### Установка

**Windows:** запустите установщик `.exe`. Нужен WebView2; при его отсутствии установщик может скачать среду Microsoft. Обновление официальной установки сохраняет идентификатор приложения и настройки. Бета не подписана доверенным сертификатом, поэтому Windows может показать предупреждение SmartScreen или неизвестного издателя. Перед запуском проверьте источник файла и контрольную сумму.

**macOS:** выберите DMG для своего процессора, откройте его и перенесите Folden в **Applications**. Бета имеет ad-hoc подпись и не нотарифицирована. Если macOS заблокирует первый запуск, проверьте источник и контрольную сумму, затем разрешите открытие через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. См. [инструкцию Apple](https://support.apple.com/ru-ru/102445).

**Linux:** у этой беты нет официального пакета; проверок на компьютере с Linux пока не зафиксировано. Можно [собрать неизменённые исходники для собственного использования](docs/DEVELOPMENT.ru.md#самостоятельная-сборка-на-linux); распространение сборок запрещено.

## Работа с документами

- Визуальный редактор Markdown и режим исходного текста, вкладки и две панели.
- Дерево папки проекта, поиск по проекту, быстрое открытие, поиск и замена в документе.
- Заголовки, списки, задачи, таблицы, блоки кода, оглавление и карта документа.
- Импорт и вставка локальных изображений, относительные ссылки на документы и история переходов.
- Шаблоны пустого документа, заметки, игрового дизайн-документа и видеосценария.
- Автосохранение, восстановление и сравнение внешних изменений при конфликте.
- Создание, переименование, перенос файлов и удаление через системную корзину.
- Печать и сохранение в PDF через системный диалог.
- Русский и английский интерфейсы, настройка размеров текста и тёмная тема.

Откройте папку или Markdown-файл. Новый черновик нужно сначала **сохранить**, выбрав имя и место для файла. После этого его можно сохранять автоматически. Во время работы можно переключаться между визуальным режимом и исходным текстом.

| Действие         | Windows / Linux     | macOS       |
| ---------------- | ------------------- | ----------- |
| Сохранить        | `Ctrl+S`            | `⌘S`        |
| Быстрое открытие | `Ctrl+P`            | `⌘P`        |
| Поиск / замена   | `Ctrl+F` / `Ctrl+H` | `⌘F` / `⌘H` |
| Печать / PDF     | `Ctrl+Alt+P`        | `⌘⌥P`       |

## Приватность и ограничения

Folden работает без учётной записи, телеметрии и облачной синхронизации. Документы, копии для восстановления и журналы хранятся локально. Сетевые изображения загружаются с вашего разрешения. Кнопки помощи и обратной связи открывают GitHub в браузере. Диагностический отчёт экспортируется по отдельной команде; проверяйте отчёты и скриншоты перед отправкой другим людям.

Визуальный редактор поддерживает распространённый Markdown и сохраняет неподдерживаемый синтаксис в редактируемых блоках исходного текста. Поддержка всех диалектов Markdown, одинаковые шрифты и вёрстка печати на разных системах не гарантируются. Печать и PDF зависят от системного веб-компонента и настроек принтера.

Перед сообщением об уязвимости прочитайте [политику безопасности](SECURITY.md). Не публикуйте её детали и конфиденциальные документы в открытых обращениях.

Официальные сборки **бесплатны для личных и рабочих задач, включая коммерческие**. Ваши документы принадлежат вам. Авторские исходники доступны для ознакомления; есть ограниченное разрешение собрать неизменённый код на Linux для собственного использования. Другое использование авторских материалов и распространение сборок Folden запрещены [условиями использования](LICENSE.md). Сторонние компоненты сохраняют [свои права](LICENSE.md#third-party-components). Полные тексты их лицензий входят в официальные пакеты и доступны в «О приложении → Лицензии».
