# Folden

[English](README.md) | Русский

Folden — локальный настольный редактор Markdown и обычных текстовых файлов.

Проект строится вокруг четырёх продуктовых принципов:

* local-first: пользовательские данные остаются на устройстве пользователя;
* file-first: обычные файлы остаются источником истины;
* Markdown-friendly: документы остаются читаемыми и редактируемыми за пределами Folden;
* прямота важнее «умных» решений: базовые рабочие сценарии должны быть понятными и предсказуемыми.

## Состояние

Репозиторий описывает Folden `0.6.9`: рабочий настольный редактор для Windows с нативным доступом к файлам, рабочими пространствами, вкладками, двухпанельным разделением, исходным и визуальным редактированием Markdown, автосохранением, восстановлением, обработкой внешних изменений, локальной диагностикой, сохраняемыми настройками раскладки и компактной тёмной рабочей областью.

Уже реализовано:

* нативное открытие и сохранение текстовых файлов с сохранением переводов строк и UTF-8 BOM;
* открытие рабочих пространств, ленивая загрузка каталогов, действия с деревом файлов, недавние рабочие пространства и игнорируемые имена;
* вкладки, изменение их порядка, перенос между панелями, Open Editors, двухпанельный режим, состояние активной панели, общие сессии документов, отмена и повтор действий;
* activity rail, разделы рабочего пространства и настроек, изменяемая ширина боковой панели и rail, режим фокуса, настройка плотности и сброс сохранённой раскладки;
* исходный режим на CodeMirror и визуальный режим Markdown на Tiptap с общей панелью инструментов документа;
* проверки безопасности ссылок и изображений в Visual-режиме, при этом удалённые изображения блокируются до явного разрешения пользователя;
* атомарное сохранение, обнаружение устаревшей записи, состояния отсутствующего файла и разрешение конфликтов;
* необязательное автосохранение сохранённых файлов с настройками задержки, сохранения при потере фокуса окна и при смене документа;
* сохранение сессии и восстановление после сбоя для сохранённых и черновых документов;
* интеграция с файловым watcher для обновлений рабочего пространства и документов;
* ограниченные локальные логи, открытие папки логов, экспорт диагностического отчёта и toast-уведомления;
* unit-, contract- и E2E-тесты, сборка frontend и проверки Rust.

Сейчас не реализованы: облачная синхронизация, учётные записи, совместное редактирование, мобильные приложения, backlinks, индексация SQLite, пользовательские блоки, slash-команды, API плагинов, экспортные конвейеры и произвольные сетки разделения редактора.

## Стек

* Vue 3, TypeScript и Vite для frontend.
* Tauri 2 и Rust для нативной интеграции с настольной системой.
* CodeMirror 6 для исходного и обычного текстового редактирования.
* Tiptap 3 для визуального редактирования Markdown.
* Vitest, Playwright, ESLint, rustfmt, clippy и Cargo tests для проверок.

## Требования

* Node.js и npm.
* Rust toolchain с Cargo.
* Windows C++ Build Tools с workload `Desktop development with C++`.
* Microsoft Edge WebView2 Runtime.

## Команды

Установка зависимостей:

```powershell
npm install
```

Запуск только frontend в браузере:

```powershell
npm run vue:dev
```

Запуск настольного приложения в режиме разработки:

```powershell
npm run app:dev
```

Сборка frontend:

```powershell
npm run vue:build
```

Сборка настольного приложения без установщиков:

```powershell
npm run app:build
```

Запуск последнего собранного desktop executable:

```powershell
npm run app:run
```

Запуск основного quality gate:

```powershell
npm run quality
```

Дополнительные проверки:

```powershell
npm run lint
npm run test:coverage
npm run test:e2e
```

Проверка или подготовка файлов версий при выпуске релиза:

```powershell
npm run version:check
npm run version:bump -- patch
```

Проверки Rust выполняются из `src-tauri/`:

```powershell
cargo fmt --check
cargo clippy -- -D warnings
cargo test
```

## Структура репозитория

* `src/ui` содержит Vue views, редакторы, диалоги и UI рабочего пространства.
* `src/application` содержит application facade, контроллеры, workflows, команды, ports и shell types.
* `src/domain` содержит независимые от фреймворка правила документов, рабочих пространств и Markdown, native contracts и правила сохранения/восстановления.
* `src/infrastructure` содержит browser/Tauri adapters и persistence настроек.
* `src-tauri/src` содержит нативный слой Rust и регистрацию Tauri-команд.
* `tests/unit` содержит unit-тесты domain, application controllers, infrastructure и UI.
* `tests/contracts` содержит fixtures нативных контрактов.
* `tests/e2e` содержит Playwright smoke specs, разделённые по сценариям panes/tabs, recovery/conflict, settings/autosave, shell/layout, visual safety и workspace save.
* `.github/workflows/windows.yml` содержит Windows CI quality gate.
